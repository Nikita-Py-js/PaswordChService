## [1.0.0] — 2026-10-15

Первая стабильная версия.

### Добавлено

- Периодическая автоматическая смена паролей раз в N дней (`IntervalDays`).
- Ручная смена по запросу: `change`, `run`, `runall`.
- Поддержка двух режимов: локальные пользователи (`Mode=Local`) и Active Directory (`Mode=AD`).
- Ролевая модель: обычный пользователь / менеджер / защищённый логин.
- Работа без прав администратора через именованный канал `\\.\pipe\PaswordChService`.
- Проверка личности клиента через `GetImpersonationUserName`.
- HTML-письма в фирменном стиле:
  - `EmailUser.html` — письмо пользователю с новым паролем;
  - `EmailAdmin.html` — отчёт администраторам с таблицей результатов.
- Настраиваемый брендинг: логотип, слоган, контакты, строка вендора.
- Настраиваемые темы писем с плейсхолдерами (`{{UserName}}`, `{{ClientCompanyName}}`, `{{CompanyName}}`, `{{TotalSuccess}}`, `{{TotalErrors}}`).
- Retry при временных ошибках SMTP (5/15/30 с).
- Троттлинг между письмами (1 сек).
- AES-256-шифрование ZIP-архивов с новыми паролями (PBKDF2, 100 000 итераций).
- Удаление открытого CSV после упаковки в ZIP.
- Шифрование секретов `my.ini` через Windows DPAPI:
  - `AdAdminPassword`;
  - `ZipPassword`;
  - `SmtpPassword`.
- Автоматическое зашифрование открытых секретов при старте службы (`SealSecrets`).
- Команды управления секретами: `seal`, `unseal`, `encrypt`, `decrypt`.
- Единый каталог для всех данных: `C:\Program Files\PaswordCh\`.
- Мультилогирование: файл + EventLog + консоль.
- Автоматическая ротация логов (`LogArchiveHours`).
- Автоматический перезапуск при сбоях через `sc failure`.
- Поддержка любых кодировок `my.ini`: UTF-8 (с/без BOM), UTF-16 LE/BE, Windows-1251.
- Отладочный режим `console` с живым логом в окне.
- Проверка прав администратора перед операциями с SCM (`install`, `start`, `stop`, ...).
- Понятные сообщения об ошибках на русском.

### Известные ограничения

- Шифрование `ENC:` через DPAPI привязано к машине. Перенос `my.ini` на другой сервер требует `unseal` заранее.
- Утилита расшифровки ZIP-архива не входит в комплект.
- Валидация email перед отправкой не выполняется (SMTP может принять письмо и отправить в никуда).
- Нет встроенной интеграции с событийной моделью Windows для триггеров на смену пароля пользователем.

## Формат версий

`MAJOR.MINOR.PATCH`:
- **MAJOR** — несовместимые изменения `my.ini` или структуры каталогов;
- **MINOR** — новые функции, обратная совместимость;
- **PATCH** — исправления ошибок.
