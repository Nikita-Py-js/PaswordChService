# Команды

← [Назад к README](../README.md) · [← Конфигурация](CONFIG.md) · [Далее: Архитектура →](ARCHITECTURE.md)

Все команды запускаются из `PaswordChService.exe`:

```bat
"C:\Program Files\PaswordCh\PaswordChService.exe" <команда> [аргументы]
```

Без аргументов — справка.

---

## Для всех пользователей

| Команда | Что делает |
|---|---|
| `whoami` | Показать логин, роль (обычный / менеджер / защищённый) |
| `ping` | Проверить связь со службой |
| `change` | Сменить **свой** пароль |
| `change <user>` | Сменить пароль другого пользователя (только менеджер) |
| `nextrun` | Показать, когда следующая автоматическая смена |
| `testmail [to]` | Отправить тестовое письмо через SMTP |

### Пример

```bat
> PaswordChService.exe whoami
Текущий пользователь: AD-CLIENT\test
Роль: ОБЫЧНЫЙ — может менять только свой пароль.

> PaswordChService.exe change
Пользователь: AD-CLIENT\test
Запрос на смену пароля для: test
Выполняется... готово.

========================================
  Новый пароль: Kd8#nQp3Wm2x
========================================
```

Работает **без прав администратора** — запрос уходит в службу через именованный канал.

---

## Для менеджеров

| Команда | Что делает |
|---|---|
| `run` | Массовая смена — все пользователи из `emails.csv` |
| `run <user1> <user2> ...` | Выборочная смена (разделитель — пробел) |
| `run <user1>;<user2>` | То же, разделитель `;` |
| `runall` | То же, что `run` без аргументов |

### Пример

```bat
> PaswordChService.exe run test admin

Пользователь: AD-CLIENT\efsol_dc
Запрос: сменить пароли для test, admin (через службу)

================ РЕЗУЛЬТАТЫ ================
[OK]     admin                email=admin@efsol.ru               пароль: Hk7#mPq2Ld9a
[OK]     test                 email=test@efsol.ru                пароль: Rt4@nWx8Ke3b
============================================
Успешно: 2   Ошибок: 0
```

Тоже без прав администратора — через службу.

---

## Для администраторов

### Управление службой

| Команда | Что делает |
|---|---|
| `install` | Установить службу (аналог `ServiceInstall.bat`) |
| `uninstall` | Удалить службу |
| `start` | Запустить службу |
| `stop` | Остановить службу |
| `console` | Отладка: запуск службы в консольном режиме |

**Требуют прав администратора Windows.** Без них — понятное сообщение и выход с кодом 5.

### Ручные операции (в обход службы)

| Команда | Что делает |
|---|---|
| `run` / `runall` | Массовая смена напрямую (не через pipe) |
| `run <users>` | Выборочная смена |

Работает быстрее, но требует прав админа. Через `run` под администратором не нужно указывать себя в `Managers`.

### Работа с секретами

| Команда | Что делает |
|---|---|
| `seal` | Зашифровать все открытые пароли в `my.ini` |
| `unseal` | Расшифровать обратно (с подтверждением) |
| `encrypt <text>` | Зашифровать одно значение, вернуть `ENC:...` |
| `decrypt <ENC:...>` | Расшифровать одно значение |

### Отладка

| Команда | Что делает |
|---|---|
| `console` | Запуск службы в консольном режиме с выводом логов в реальном времени |
| `testmail [to]` | Проверка SMTP |

## `console` — что это и зачем

`PaswordChService.exe console` запускает **ту же логику службы**, но не через SCM, а как консольное приложение:

- всё логируется в окно в реальном времени;
- можно ставить breakpoints в отладчике;
- сразу выполняется цикл `RunOnce` (если наступил срок);
- остановка — по Enter.

**⚠️ Одновременно с установленной службой работать не будет** — pipe уже занят:

```
[ERROR] Ошибка pipe-сервера :: IOException: Все экземпляры канала заняты.
```

Перед `console` — остановите службу:
```bat
sc stop PaswordChService
"C:\Program Files\PaswordCh\PaswordChService.exe" console
:: ... поработали ...
sc start PaswordChService
```

**⚠️ `console` реально меняет пароли.** Это не «сухой прогон». Если наступил срок — пароли изменятся, письма уйдут, ZIP создастся.

---

## Коды возврата

| Код | Значение |
|---|---|
| `0` | Успех |
| `1` | Ошибка конфигурации / внутренняя ошибка |
| `2` | Служба недоступна |
| `3` | Пустой ответ от службы |
| `4` | Ошибка операции (нет прав, защищённый логин и т. п.) |
| `5` | Не хватает прав администратора |

---

## Работа через named pipe

Команды `change`, `run`, `ping` для непривилегированных пользователей работают через именованный канал `\\.\pipe\PaswordChService`:

1. Клиент подключается к каналу.
2. Отправляет `ID|<DOMAIN\user>` — свою идентификацию.
3. Служба проверяет личность через `GetImpersonationUserName` и сверяет с заявленным.
4. Отправляется команда (`CHANGE|user` или `RUN|users`).
5. Служба выполняет операцию и возвращает результат.

Подробнее — [ARCHITECTURE.md](ARCHITECTURE.md).
